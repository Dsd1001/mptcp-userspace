Authentication

Transport Key

MPX/4 的认证根凭据。默认隐藏，不会显示在普通客户端偏好设置中。

Distribution

Client API URL

完整 URL 是 bearer credential。自定义标识只改变可读路径，随机 Secret 仍保持 256-bit。

修改标识会自动轮换 Secret，使旧 URL 立即失效。
建议通过 HTTPS 分发，并把 URL 当作密码管理。反向代理日志应隐藏 /v1/config/ 路径。

删除 Profile

删除后，对应 API URL 立即失效；已经下载的客户端缓存不会被服务器撤回。
